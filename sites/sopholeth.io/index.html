01 / FIRST STEPS

Start locally.

With Go 1.22 or later, from the source checkout:

TERMINAL / PRIVATE NODE
go build -o bin/server ./cmd/server
NODE_NETWORK=private \
  NODE_MAX_STORAGE_MB=50 \
  ./bin/server

The HTTP API listens on port 8080 on all interfaces. Private mode uses manual peer discovery.
