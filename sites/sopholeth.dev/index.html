Meet Sopholeth.

REPRAM has a new name: Sopholeth. Pronounced SOF-oh-leth, it carries the idea at the heart of the project: wisdom through intentional forgetting.

The rebrand is now in the code and documentation. Service commands are named for their roles, and the client command soph is reserved for the CLI still to come.

Next on the horizon: the first public network, a demo application, and a probe simulation.

Temporary state. Deliberate progress.
